NMDS Guide

Non-metric Multidimensional Scaling

What is NMDS?

NMDS is a rank-based ordination method that preserves the rank order of dissimilarities between samples. It's ideal for ecological data with non-linear relationships.

Stress Interpretation

  • < 0.05: Excellent representation
  • < 0.10: Good representation
  • < 0.20: Usable representation
  • > 0.20: Poor representation (increase dimensions or check data)

Key Parameters

Distance Metric

  • Bray-Curtis: Default for abundance data
  • Jaccard: Presence-absence data
  • Euclidean: Continuous environmental data

Dimensions (k)

Start with k=2 for visualization. If stress is high (>0.20), try k=3.

💡 Best Practice: Always check stress! Multiple runs may converge to different solutions - NMDS finds local minima.
