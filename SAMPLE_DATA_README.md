# Sample Datasets for Ördin Testing

## Overview
These sample datasets are extracted from the **vegan** package in R and represent classic ecological community data from dune meadow vegetation studies.

## Files

### 1. `sample_data_species.csv`
**Species Composition Data**
- **Format:** Abundance data (counts)
- **Dimensions:** 20 sites × 30 species
- **Description:** Plant species abundance at 20 dune meadow sites
- **Data type in Ördin:** Abundance (for iNEXT diversity estimation)

**Species list (abbreviated codes):**
- Achimill (Achillea millefolium)
- Agrostol (Agrostis stolonifera)
- Airaprae (Aira praecox)
- Alopgeni (Alopecurus geniculatus)
- And 26 more species...

**Column structure:**
```
Site,Achimill,Agrostol,Airaprae,...
Site_1,1,0,0,...
Site_2,3,0,0,...
```

### 2. `sample_data_environment.csv`
**Environmental Variables Data**
- **Dimensions:** 20 sites × 5 variables
- **Description:** Environmental conditions at each site
- **Use:** For constrained ordination analyses (CCA, RDA)

**Environmental variables:**
1. **A1** - Soil thickness (cm) - Continuous
2. **Moisture** - Moisture level (1-5 scale) - Ordinal
3. **Management** - Management type - Categorical
   - BF (Biological Farming)
   - HF (Hobby Farming)
   - NM (Nature Management)
   - SF (Standard Farming)
4. **Use** - Land use type - Categorical
   - Hayfield
   - Haypastu (Hay pasture)
   - Pasture
5. **Manure** - Manure application (0-4 scale) - Ordinal

**Column structure:**
```
Site,A1,Moisture,Management,Use,Manure
Site_1,2.8,"1","SF","Haypastu","4"
Site_2,3.5,"1","BF","Haypastu","2"
```

## How to Use in Ördin

### Testing Diversity Analysis
1. Go to **Data** tab
2. Click **Import** sub-navigation
3. Upload `sample_data_species.csv`
4. Switch to **Edit** to view the data
5. Go to **Diversity Analysis** tab
6. Run **Estimation** (iNEXT) or **Indices** (vegan)

### Testing Ordination Analysis
1. Load `sample_data_species.csv` as Species Data
2. Load `sample_data_environment.csv` as Environment Data
3. Go to **Ordination** tab
4. Select method (PCA, CA, DCA, CCA, or RDA)
5. For constrained ordination (CCA/RDA), environment data will be used
