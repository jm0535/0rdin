Installation Guide

Windows Installation

1

Download the installer

Download Ordin-3.0.0.Setup.exe from the link above

2

Run the installer

Double-click the .exe file. Windows SmartScreen may appear—click "More info" → "Run anyway"

3

Follow the wizard

Accept the license, choose installation location (default: C:\Program Files\Ordin)

4

Launch Ördin

Find Ördin in Start Menu or desktop shortcut. First launch shows splash screen.

Note: No R installation required—everything is bundled!

macOS Installation

Status: macOS build not yet available. Building macOS packages requires a macOS system.

Check the releases page for future macOS builds.

Alternatively, you can run Ördin on macOS by installing R and running the Shiny app locally.

Linux Installation

Debian/Ubuntu (.deb)

# Download the package
wget https://github.com/jm0535/0rdin/releases/latest/download/ordin_3.0.0_amd64.deb

# Install with dpkg
sudo dpkg -i ordin_3.0.0_amd64.deb

# Fix missing dependencies (if any)
sudo apt-get install -f

# Launch Ördin
ordin

Fedora/RHEL (.rpm)

# Download the package
wget https://github.com/jm0535/0rdin/releases/latest/download/ordin-3.0.0-1.x86_64.rpm

# Install with dnf
sudo dnf install ordin-3.0.0-1.x86_64.rpm

# Launch Ördin
ordin

Generic Linux (AppImage - Coming Soon)

# Make executable
chmod +x Ordin-3.0.0-x86_64.AppImage

# Run
./Ordin-3.0.0-x86_64.AppImage

Dependencies: Most are bundled, but you may need: libgtk-3-0, libnss3
