Installation Guide

✨ Windows - Two Installation Options

⚡ PORTABLE VERSION (Recommended): No installation required!

Or use the traditional installer for system-wide installation

Option 1: Portable Version (Recommended)

1

Download the Portable ZIP

Download Ordin-win32-x64-3.0.0.zip (770 MB) from the download button above

2

Extract the ZIP file

Right-click the ZIP file → Select "Extract All..." → Choose any location (Desktop, Documents, or USB drive)

3

Launch Ördin

Open the extracted folder → Double-click ordin.exe → Application starts immediately!

4

Start Analyzing

Splash screen appears briefly, then the main window opens. You're ready to analyze your ecological data!

✅ Why Portable?

  • No admin rights needed
  • No installation wizard
  • Works immediately after extraction
  • Fully self-contained with R 4.5.1
  • Perfect for USB drives
  • Run multiple versions side-by-side

Option 2: Traditional Installer

⚠️ Status: Traditional Windows installer coming in a future update.

Note: The portable ZIP version works perfectly and includes all the same features. It's actually recommended for most users as it requires no installation and can run from anywhere!

1

Download the Installer

Download Ordin-3.0.0-Setup.exe (770 MB) from the download button above

2

Run the Installer

Double-click the installer → Follow the installation wizard → Choose installation location

3

Launch from Start Menu

After installation, find Ördin in your Start Menu or Desktop shortcut

Linux Installation

Debian/Ubuntu (.deb)

# Download the package
wget https://github.com/jm0535/0rdin/releases/latest/download/ordin_3.0.0_amd64.deb

# Install with dpkg
sudo dpkg -i ordin_3.0.0_amd64.deb

# Fix missing dependencies (if any)
sudo apt-get install -f

# Launch Ördin
ordin

Fedora/RHEL (.rpm)

# Download the package
wget https://github.com/jm0535/0rdin/releases/latest/download/ordin-3.0.0-1.x86_64.rpm

# Install with dnf
sudo dnf install ordin-3.0.0-1.x86_64.rpm

# Launch Ördin
ordin

Generic Linux (AppImage - Coming Soon)

# Make executable
chmod +x Ordin-3.0.0-x86_64.AppImage

# Run
./Ordin-3.0.0-x86_64.AppImage

Dependencies: Most are bundled, but you may need: libgtk-3-0, libnss3
