Instructions

  1. Download the icon.png file (256×256 recommended for general use)
  2. Download the icon-512.png for high-resolution displays
  3. Replace the existing files in the build/ directory
  4. For Windows taskbar, the 256×256 PNG works best
  5. For macOS dock, use 512×512 or 1024×1024
  6. Rebuild the app: npm run make

Note: The icon uses green (#2e8b57) on dark background (#2d2d30)
